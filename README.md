# 🎓 Student Performance Regression

A Machine Learning regression project that analyzes student-related factors and predicts student performance using Python and Scikit-learn.

## 📌 Project Overview

Student performance can be influenced by several academic and personal factors such as study time, attendance, previous performance, and other student characteristics.

This project uses **Exploratory Data Analysis (EDA)** and **Machine Learning Regression** techniques to understand the dataset and build a model capable of predicting student performance.

The complete analysis and model implementation are available in the Jupyter Notebook.

---

## 🎯 Objectives

- Understand the student performance dataset
- Perform data cleaning and preprocessing
- Explore relationships between different features
- Visualize important patterns in the dataset
- Select relevant features for prediction
- Train a regression model
- Evaluate model performance
- Predict student performance based on input features

---

## 🛠️ Technologies Used

- **Python**
- **Jupyter Notebook**
- **Pandas** – Data manipulation
- **NumPy** – Numerical computation
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Scikit-learn** – Machine Learning
